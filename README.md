# Data and AI with Gemini: Corporate Workshop

Three-day hands-on workshop (Google Colab + Gemini API) built around a fictional airport case, the "Friday Problem".

| Folder | What is in it |
|---|---|
| `docs/` | Multi-page workshop website (publish with GitHub Pages: Settings, Pages, branch `main`, folder `/docs`) |
| `index_single_file.html` | The whole website as one file |
| `notebooks/` | Day 1 Colab notebooks (data, documents, models/system prompt/context) and helper scripts |
| `data/` | Synthetic airport database (`airport_ops.db`), data dictionary, 12 policy documents (TXT and PDF) |
| `slides/` | Day 1 opening deck (AI in thirty minutes) and the Day 1 workshop slides |
| `handouts/` | Participant handbook and workshop handout (print-ready PDFs) |
| `release_later/` | Day 2 and Day 3 notebooks, slides and guides: publish after each day |
| `source/` | Generator scripts for the site, notebooks and deck |

All data is fictional. Never put real or personal data into an AI tool. Keep API keys in Colab Secrets, never in the repo.

Not included on purpose: answer key and facilitator notes.
