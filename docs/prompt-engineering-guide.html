Prompt Engineering Guide

An airport manager has a feeling about Friday evenings. Write the prompt that turns that feeling into a checkable answer. Type each part yourself. Checks show what is missing as you type.

Decoding Data Science. The checks run in your browser and nothing is sent anywhere. They look for the parts of a good prompt. They cannot tell you the answer will be right, so always test your prompt in Copilot or Gemini and check the numbers. All data and organisations in the workshop are fictional.
